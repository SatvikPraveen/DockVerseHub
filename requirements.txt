# Location: ./requirements.txt
#
# DockVerseHub - runtime dependencies for the repository tooling
# (utilities/, research/ benchmark harness, lab helper scripts).
#
# Design rules:
#   * Only packages actually imported by code in this repository.
#   * Lower bounds only, so `pip install -r requirements.txt` resolves on
#     current CPython (3.10 - 3.13). Fully pinned, hash-locked snapshots for
#     archival reproducibility live in research/requirements-lock.txt.
#   * The deprecated `docker-compose` PyPI package is intentionally absent:
#     it pins PyYAML<6 and cannot co-exist with pyyaml>=6. Compose v2 is a
#     Docker CLI plugin (`docker compose`) and needs no Python package.
#
# Development, linting and test tooling is in requirements-dev.txt.
